## Что построено — полный список фич

### Мета-игра «Гнездо»

- Изометрическое строительство из «хлама» на сетке
- **3 региона:** квартира (7 точек), балкон (5), подъезд (4) — **16 районов** на карте мира
- **9 типов построек:** кухня, спальня, кладовая, питомник, лазарет, клумба, укрытие, шкафчик, ниша
- Апгрейды до 5 уровня (питомник/лазарет — до 3)
- Экономика: еда, деньги, здоровье; пассивный доход
- Ловушки для защиты: тапок, спрей, клей
- Переключатель регионов с блокировкой по прогрессу

### Аркады (5 мини-игр)

| Игра | Награда |
|------|---------|
| Уворот от тапка | Счёт, таблица лидеров |
| Дихлофос | Еда, деньги |
| Поиск еды | +40 еды |
| Побег от кота | Еда, деньги |
| Лазарет (тайминг) | +30 HP |

Управление: клавиатура на ПК, джойстик/тач на мобильных.

### Карта мира и налёты

- Трёхфазные рейды: проникновение → ограбление → побег
- Энергия: 3 в день, сброс в полночь; лимит 5 налётов/день
- Щит 24ч от контратак (IAP или сезонный пропуск)
- Рекламный бонус «удвоить добычу» перед налётом

### Разведение

- Роли: **рабочий**, **разведчик**, **боец**
- Таймер вылупления, лимит по уровню питомника

### Ежедневные системы

- Ежедневный бонус со streak
- 3 квеста в день (сброс в полночь)
- Еженедельные live-ops ивенты (5 типов множителей)

### Сезонный пропуск (NEW v0.3.0)

- 15 уровней, календарный месяц
- XP за квесты, налёты, аркады, стройку
- Бесплатная и премиум ветки наград
- IAP `season_pass_premium` открывает премиум-трек

### Скины таракана (NEW v0.3.0)

- default, golden, neon, zombie, chef
- Награды сезонного пропуска + IAP `skin_pack` (все скины сразу)

### Монетизация

- **8 IAP-товаров** (см. раздел ниже)
- Межстраничная реклама (каждая 3-я аркада, пауза 60 сек)
- Rewarded: удвоение налёта, +энергия, мгновенная постройка

### Социальное и платформы

- 3 таблицы лидеров (тапок, рейтинг налётов, размер колонии)
- Адаптеры: Web, Yandex Games, Steam (Electron), Билайн/Мегафон
- RU / EN локализация
- Облачное сохранение на Yandex / операторах
- Аналитика событий

### Графика и полировка (NEW v0.3.0)

- **Процедурная генерация текстур** — UI, здания, фоны аркад, карта, эффекты
- Favicon и Open Graph для веб-шаринга
- Адаптивный mobile UI (375px)
- Режим скриншотов для стора (`?screenshot=…`)

## Как опубликовать на каждой площадке

### Яндекс Игры

1. `npm run build:yandex`
2. Заархивировать **содержимое** папки `dist/` (не саму папку)
3. [Консоль Яндекс Игр](https://games.yandex.ru/console):
   - Загрузить zip
   - Скопировать тексты из `store-assets/descriptions/yandex-ru.md` и `yandex-en.md`
   - Синхронизировать ID из `yandex-games.config.json` (лидерборды, IAP, whats_new)
   - Загрузить icon-512.png, cover-800x470.png, 6 скриншотов
4. Настроить рекламу и IAP в консоли
5. Отправить на **модерацию**

Подробнее: [docs/DEPLOYMENT.md](./DEPLOYMENT.md), [docs/RELEASE_CHECKLIST.md](./RELEASE_CHECKLIST.md)

### Steam

1. Получить App ID в Steamworks → записать в `steam/steam_appid.txt`
2. `npm run electron:build` → артефакты в `electron/out/`
3. Заполнить страницу из `store-assets/descriptions/steam-en.md` (+ RU)
4. Загрузить депо через SteamPipe
5. **Внимание:** нативный Steamworks SDK пока заглушка — нужна интеграция перед релизом

Подробнее: [steam/README.md](../steam/README.md)

### Операторы (Билайн / Мегафон)

1. Получить API URL и ключ от портала
2. Собрать с env-переменными (`VITE_OPERATOR_BEELINE_*` / `VITE_OPERATOR_MEGAFON_*`)
3. Передать билд порталу; пройти iframe/postMessage QA
4. Согласовать рекламу и биллинг (те же 8 product ID)

Подробнее: [docs/OPERATOR_PORTALS.md](./OPERATOR_PORTALS.md)

### Web (самостоятельный хостинг)

1. `npm run build`
2. Залить `dist/` на HTTPS-хостинг
3. Для подпапки: `$env:VITE_BASE_PATH="/games/cockroach/"; npm run build`
4. Проверить favicon и OG-превью в соцсетях

## Реалистичные ожидания по доходу

> Оценки для **инди casual HTML5** на Яндекс Играх без платного трафика. Не обещание, а ориентир для планирования.

| Метрика | Первый месяц | При попадании в подборки (3–6 мес.) |
|---------|--------------|-------------------------------------|
| DAU | 50–500 | 1 000–10 000+ |
| ARPDAU (реклама) | ₽0,5–3 | ₽1–5 |
| Конверсия IAP | 0,3–1.8% | 0,5–1,5% |
| Доля remove_ads / season pass | Единичные покупки | Стабильный хвост |

**Практически:**

- **Реклама** — основной доход первые месяцы; rewarded даёт больше, чем interstitial.
- **IAP** — `remove_ads` и `season_pass_premium` принесут больше, чем consumable-паки еды.
- **Steam / операторы** — отдельные каналы; без договоров доход = 0.
- Не закладывать в бюджет «виral hit» — рост зависит от модерации, ASO в каталоге Яндекса и удержания D1/D7.

Рекомендация: первые 2 недели смотреть retention D1 и среднюю длину сессии в аналитике; при D1 < 25% — доработать туториал и daily loop, не лить трафик.

## Известные ограничения

1. **Steam** — Electron-обёртка есть, Steamworks API не подключён нативно.
2. **Операторы** — postMessage-протокол реализован; реальные API ключи и ad SDK нужны от портала.
3. **Google Play** — только описание и план; APK/TWA не собран.
4. **OG image** — относительный путь `/icon-512.png`; для корректного превью в соцсетях нужен **абсолютный URL** после деплоя (настроить в meta или через хостинг).
5. **Скриншоты в репозитории** — могут быть placeholder; перед публикацией переснять на v0.3.0 UI.
6. **Баланс** — экономика и season pass не проходили A/B; возможны правки после live-метрик.
7. **Один разработчик** — hotfix-процесс через git + ручная заливка zip в Яндекс.

## Рекомендуемые следующие шаги (понедельник)

### День 1 — публикация Яндекс

1. Снять 6 скриншотов (nest, slipper, raid, map, breeding, shop/season pass)
2. Заполнить консоль по [RELEASE_CHECKLIST.md](./RELEASE_CHECKLIST.md) §3
3. Загрузить билд `build:yandex`, отправить на модерацию
4. Параллельно: smoke-test на телефоне через preview-URL

### Неделя 1 — после модерации

1. Мониторинг DAU, crashes, отзывов
2. Если reject — исправить по комментариям модерации (часто: реклама, возраст, описание IAP)
3. A/B заголовка/обложки в каталоге (если доступно)

### Месяц 1 — v0.3.1 / v0.4.0

1. Баланс season pass по данным конверсии premium
2. 1–2 новых live-ops ивента или район (если retention OK)
3. Steamworks — если есть App ID
4. Переговоры с одним оператором (Билайн или Мегафон)
