# Steam Store Page — Cockroach Life (English)

## Short description
Build a junk nest, breed your colony, raid rival roaches, and survive slipper dodging — all from a cockroach's POV in this isometric life sim with arcade minigames.

## About the game

**Cockroach Life** drops you on the kitchen floor of Apartment 47 with one goal: grow from a lone scuttler into the dominant colony in the building.

This is not a horror game — it's a cozy-strategic survival sim with tongue-in-cheek humor. You manage food, money, and health while constructing rooms from everyday trash: a cardboard kitchen, a sock bedroom, a tin-can storage, an egg-carton nursery. Tap the isometric grid to build, upgrade to level 5, and wire traps to defend against incoming raids.

When the nest needs resources, send your roach into **arcade missions**: dodge a human slipper, outrun bug spray, hunt crumbs before starvation, escape a curious cat, or heal in the hospital timing minigame. High scores feed global leaderboards on supported platforms.

The **world map** reveals rival districts — Fridge Colony, Trash Gang, Pot Guild — each with power ratings and loot. Launch **three-phase raids**: infiltrate, loot crumbs from enemy nests, then escape before the slipper lands. Energy limits and 24-hour shields add tactical depth.

**Breeding** unlocks Workers, Scouts, and Fighters with stacking colony bonuses. **Weekly live events** rotate bonuses (double slipper score, cheaper builds, raid loot multipliers). **Daily login streaks** and quests keep sessions rewarding.

Fully localized in **English and Russian**. Touch controls and mobile layout included; desktop build via Electron wrapper.

## System requirements

**Minimum**
- **OS:** Windows 7 / macOS 10.13 / Linux (Ubuntu 18.04+) — or any modern browser
- **Processor:** Dual-core 1.5 GHz
- **Memory:** 2 GB RAM
- **Graphics:** WebGL 1.0 compatible GPU
- **Storage:** 150 MB available space
- **Additional:** Internet for leaderboards and optional ads/IAP on web builds

**Recommended**
- **OS:** Windows 10/11, macOS 12+, or current Chrome / Firefox / Edge
- **Memory:** 4 GB RAM
- **Graphics:** Hardware-accelerated WebGL 2.0

**Browser (free web version)**
- Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- JavaScript enabled; 1280×720 viewport recommended (scales down to mobile)

**Steam / Electron build**
- Same as minimum; packaged Chromium runtime included (~120 MB)
- No separate GPU driver requirements beyond integrated graphics

**Notes:** Game is HTML5/WebGL — no DirectX version. Controller not required; keyboard and mouse or touch supported.
