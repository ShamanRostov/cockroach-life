# Статус выборок — 2026-09-15

## Что сделано в этой итерации

- Архив новостей расширен: RSS + **MOEX sitenews** + GDELT (сектора)
- Дедуп по нормализованному заголовку
- Фильтр биржевого шума (облигации / «о порядке…» / вакансии)
- Секторные GDELT-запросы с RU/EN и russia-контекстом
- Порог движения цены `min_move_pct=0.2%`, якорь к ближайшей сессии
- Валидация: hit_rate ≥70%, `min_samples` (сейчас 5, цель 8–10), Wilson → `strong_valid`
- Документ плана: `docs/ROADMAP.md`

## Узкое место

Не объём «сырых» новостей, а **число событий с явной тональностью по тикеру**, пересекающихся с часовыми свечами. Лента MOEX почти вся про облигации → правильно отфильтровывается, но не даёт сигналов.
